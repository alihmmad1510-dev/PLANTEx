PLANET X - first playable build
================================

HOW TO RUN
1. Unzip the folder.
2. In the PLANET-X folder, start a local server:
     python3 -m http.server 8000
   Then open http://localhost:8000 (on a tablet, use your computer's LAN IP).
3. Three.js loads from the jsDelivr CDN, so an internet connection is required.

WHAT IS IN THIS BUILD
- Create your planet: name, 4 planet types with procedural textures, glow colour, live preview.
- Walk mode: stand on your planet, look around 360 degrees, walk with the on-screen stick
  or W A S D / arrow keys. Tap buildings to open their menus.
- Bank (5 levels), City (5 levels), Cosmic Bomb (6 levels, price x5 each step), Spaceship (5 levels,
  price x3 each step) and a small hangar at the launch pad.
- Power: Cosmic Bomb upgrades add their cost to Power. Milestones 100 / 500 / 1,000 / 10,000 /
  100,000 trigger cartoon events (no real-world content) and give +5 gems the first time.
- Tap the Cosmic Bomb to get a coin bonus with a light ring and sparkles.
- Exploration: 4 destinations with unlock conditions, travel time, resource yields and missions.
- Daily rewards: 7-day cycle, one claim per local calendar day.
- Gems: spent on 6 Cosmic Bomb colours (10 gems each), chosen in the Cosmic Bomb panel.
- Save: localStorage, auto-save every 15 s and on important actions. Offline earnings (max 4 h).
- Settings: effects level, planet look, reset progress, credits.

NOT BUILT YET
- Character customisation, COSMIC FUSION machine, gem shop beyond Cosmic Bomb colours.
- Trips do not survive a page reload (progress is saved, but an active trip is lost).

ASSETS
- Everything is generated by code (planet textures, buildings, ships, Cosmic Bomb, scenery).
- No real weapon models, sounds or third-party assets are included.
- Optional: CC0 textures from polyhaven.com or ambientCG.com can be added. Check each asset's licence.
- Icons are emoji. No third-party models or sounds are included.


RENDER DEPLOYMENT FILES
- package.json: dependencies and start script
- server.js: web server + basic Socket.IO room messaging
- render.yaml: Render web-service Blueprint

DEPLOY
1. Upload all files in this folder to a GitHub repository.
2. In Render, choose New > Blueprint and connect that repository.
3. Render reads render.yaml; review the plan and deploy.
4. The server will expose /health and Socket.IO room events.

NOTE: This adds the server infrastructure and room message endpoints, but
the existing game client is not yet wired to join rooms or synchronize players.
That client integration is a separate gameplay update.
